# РК1 по ПиКЯП — вариант Б-14

**Студент:** Леонтьев Дмитрий Алексеевич (ИУ5-32Б).  
**Предметная область № 14:** CD-диск — библиотека CD-дисков.  
**Вариант запросов:** Б.

Основа решения — [официальное задание РК1](https://github.com/ugapanyuk/courses_current/blob/main/python/rk/pcpl/pcpl_rk_1.pdf). В нём требуется реализовать связи «один-ко-многим» и «многие-ко-многим», три запроса варианта Б и предоставить PDF с текстом программы и результатом её выполнения.

Для третьего запроса фамилия сотрудника из общего условия перенесена на **фамилию исполнителя CD-диска**. Длительность записи в минутах служит количественным признаком класса «CD-диск». Для второго запроса варианта Б используется число дисков, поэтому длительность не участвует в расчёте.

## Файлы

- `main.py` — модель предметной области, тестовые данные и три запроса.
- `test_main.py` — проверки результатов запросов.
- `РК1_Леонтьев_Б14.pdf` — отчёт с исходным кодом и результатом запуска.

## Запуск

```bash
python3 main.py
python3 -m unittest -v
```

Сторонние библиотеки для запуска решения не требуются. Сортировка во втором запросе выполнена по возрастанию числа дисков; при равенстве — по названию библиотеки.
